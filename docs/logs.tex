\section*{Key Empirical Insights}

\begin{enumerate}
  \item \textbf{High Fidelity on Standard Baselines:} IndicConformer-600M achieves its strongest accuracy on standard reference dialects, such as Standard Khariboli Hindi D3 (9.28\% RNNT WER) and Standard Pune Marathi D3 (10.87\% RNNT WER).
  \item \textbf{Severe Sub-Dialect Degradation Gap:} Across all languages, sub-dialects exhibit severe WER degradation compared to standard baseline dialects. For example, South Konkan Marathi D1 exhibits a \textbf{+23.50\% absolute WER increase} over Standard Pune D3, while Kannada D4 exhibits a \textbf{+41.18\% absolute WER gap} over Standard Kannada D2.
  \item \textbf{Impact of Language Token Conditioning:} Evaluating Marathi speech using Konkani language conditioning (\texttt{kok}) increases Normalized WER from \textbf{23.71\% to 54.46\%} (+30.75\% WER gap), demonstrating that IndicConformer's internal cross-attention layers strictly bind vocabulary sub-spaces based on the input language token.
  \item \textbf{South Konkan (D1) Phonological Affinity:} Under Konkani model conditioning, South Konkan (D1) achieves the lowest error rate among regional sub-dialects (50.00\% WER), reflecting the lexical and acoustic proximity between South Konkan coastal speech and Konkani.
  \item \textbf{Under-Resourced Regional Language Challenge:} Languages such as Chhattisgarhi (\textbf{58.28\% RNNT WER}) and Maithili (\textbf{48.64\% RNNT WER}) suffer from heavy phonetic and morphological divergence when evaluated using generic Hindi model conditioning.
  \item \textbf{Decoder Architecture Comparison:} Across all 9 languages, the autoregressive RNN-T decoder consistently outperforms the CTC decoder by an average of \textbf{0.51\% absolute WER}.
  \item \textbf{Justification for Post-ASR Text-to-Text Normaliser:} High substitution and insertion rates across sub-dialects demonstrate that acoustic model errors are primarily lexical and orthographic, strongly validating our proposed \textbf{Text-to-Text Normalisation Model} ($\text{Dialect Text} \rightarrow \text{Standard Formal Text}$).
\end{enumerate}

\section*{Development \& Implementation Log --- July 29, 2026}

\begin{itemize}
  \item \textbf{LLM Pipeline Engine \& LM Studio Integration:} Integrated LM Studio local inference backend (\texttt{google/gemma-4-e2b} at \texttt{http://localhost:1234/v1}) with fast health check verification and fallback to reasoning content for Gemma thinking tags.
  \item \textbf{1-Prompt-per-Sentence Architecture:} Replaced batching with 1:1 single-sentence inference (\texttt{ITEMS\_PER\_PROMPT = 1}), completely eliminating batch array length mismatches and cross-sentence context contamination.
  \item \textbf{Zero-Hallucination System Prompt Design:} Redesigned system prompt with strict semantic fidelity rules, dialectal lexical mapping tables (D1 Malvani, D2 Ahirani, D4 Varhadi), and few-shot reference examples. Verified 100\% preservation of domain terms and zero extra clause insertions.
  \item \textbf{Real-Time Per-Inference Persistence:} Updated generation pipeline to append translated rows to CSV (\texttt{marathi\_parallel\_part\_XXX.csv}) and update \texttt{pipeline\_checkpoint.json} immediately after every single inference.
  \item \textbf{Codebase Restructuring \& Package Management:} Modularized repository into \texttt{src/dialect\_norm/}, added unified CLI entrypoint (\texttt{dialect\_norm.cli}), created \texttt{tests/} suite, and registered CLI script commands in \texttt{pyproject.toml}.
\end{itemize}
