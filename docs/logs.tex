\section*{Key Empirical Insights}

\begin{enumerate}
  \item \textbf{High Fidelity on Standard Baselines:} IndicConformer-600M achieves its strongest accuracy on standard reference dialects, such as Standard Khariboli Hindi D3 (9.28\% RNNT WER) and Standard Pune Marathi D3 (10.87\% RNNT WER).
  \item \textbf{Severe Sub-Dialect Degradation Gap:} Across all languages, sub-dialects exhibit severe WER degradation compared to standard baseline dialects. For example, South Konkan Marathi D1 exhibits a \textbf{+23.50\% absolute WER increase} over Standard Pune D3, while Kannada D4 exhibits a \textbf{+41.18\% absolute WER gap} over Standard Kannada D2.
  \item \textbf{Impact of Language Token Conditioning:} Evaluating Marathi speech using Konkani language conditioning (\texttt{kok}) increases Normalized WER from \textbf{23.71\% to 54.46\%} (+30.75\% WER gap), demonstrating that IndicConformer's internal cross-attention layers strictly bind vocabulary sub-spaces based on the input language token.
  \item \textbf{South Konkan (D1) Phonological Affinity:} Under Konkani model conditioning, South Konkan (D1) achieves the lowest error rate among regional sub-dialects (50.00\% WER), reflecting the lexical and acoustic proximity between South Konkan coastal speech and Konkani.
  \item \textbf{Under-Resourced Regional Language Challenge:} Languages such as Chhattisgarhi (\textbf{58.28\% RNNT WER}) and Maithili (\textbf{48.64\% RNNT WER}) suffer from heavy phonetic and morphological divergence when evaluated using generic Hindi model conditioning.
  \item \textbf{Decoder Architecture Comparison:} Across all 9 languages, the autoregressive RNN-T decoder consistently outperforms the CTC decoder by an average of \textbf{0.51\% absolute WER}.
  \item \textbf{Justification for Post-ASR Text-to-Text Normaliser:} High substitution and insertion rates across sub-dialects demonstrate that acoustic model errors are primarily lexical and orthographic, strongly validating our proposed \textbf{Text-to-Text Normalisation Model} ($\text{Dialect Text} \rightarrow \text{Standard Formal Text}$).
\end{enumerate}

\section*{Development \& Implementation Log --- July 31, 2026}

\begin{itemize}
  \item \textbf{Comprehensive Manual Audit \& Dataset Segregation:} Conducted manual line-by-line inspection across 5,811 sentence pairs in Malvani (D1) dataset (\texttt{d1.csv}). Flagged critical translation flaws including garbled syntax, semantic inversions (e.g. \textit{पोचाक} $\rightarrow$ \textit{दिसतात}), Hindi language leakage (e.g. \textit{की विधि से}), retained dialect residue (\textit{माका}, \textit{तुका}, \textit{खय}, \textit{आसा}), and dropped question marks.
  \item \textbf{Dataset Cleaning \& Rearrangement:} Segmented the full 16,993 parallel pairs into clean dialect partitions: \texttt{d1.csv} (5,725 clean pairs), \texttt{d2.csv} (5,681 clean pairs), \texttt{d4.csv} (5,212 clean pairs), and \texttt{flawed.csv} (375 flagged pairs).
  \item \textbf{System Prompt Refinement (\texttt{sysprompt.txt}):} Updated system prompt template with strict semantic fidelity principles, financial/agricultural domain entity protection, modality locks, and zero-hallucination constraints.
  \item \textbf{NVIDIA NIM LLM Verification Engine:} Built parallel dataset verification pipeline (\texttt{dialect\_norm.data\_processing.llm_verifier}) using \texttt{llama-3.1-8b-instant} on Groq key rotation pool with fallback to NVIDIA NIM (\texttt{meta/llama-3.1-8b-instruct}). Evaluated all 16,618 synthetic parallel rows, segmenting 11,151 initial clean pairs (3,637 D1 Malvani, 3,529 D2 Ahirani, 3,985 D4 Varhadi) and extracting 5,842 flawed sentences.
  \item \textbf{Two-Step Closed-Loop Correction Engine (\texttt{correct\_flawed.py}):} Designed and executed an autonomous 2-step correction and QA auditing pipeline. Step 1 generated candidate Standard Pune Marathi translations addressing specific flaw feedback. Step 2 (QA Auditor) re-verified candidates on the fly; any audit failures were re-corrected on-the-go in Pass 2.
  \item \textbf{State-of-the-Art Dialect Normalization Benchmark:} Achieved \textbf{48.52 BLEU}, \textbf{78.49 chrF++}, and \textbf{1.0413 test loss} on D1 Malvani test set with exact length convergence (1.01$\times$ word length ratio) and clean Devanagari output generation.
\end{itemize}
